# Bah City para Windows

Instalador do **Bah City**, o jogo de mundo aberto em Porto Alegre.

**Baixar:** vá em [Releases](../../releases/latest) e baixe o arquivo `Bah-City-Setup-<versão>.exe`.

- Funciona no Windows 10 e 11 (64 bits).
- O instalador já traz a cidade, então o jogo abre mais rápido. As novidades chegam sozinhas pela internet.
- O Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**.

Não quer instalar? Jogue direto no navegador, no computador ou no celular: https://bahcity.com.br
